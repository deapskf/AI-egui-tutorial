第一部分：入门篇

﻿# 02 · 实战入门：构建一个计数器

本章模仿《The Rust Programming Language》第 2 章（猜数字游戏）的做法——先动手写出一个可运行的程序，建立感性认识，再在后续章节中逐一理解背后的原理。

在本章中，你将：

  • 用 cargo new 创建一个新项目
  • 添加 eframe 依赖
  • 写出第一个窗口
  • 实现一个可点击的计数器

2.1 创建项目

打开终端，进入你希望存放项目的目录，执行： 

cargo new counter
cd counter
这会创建一个名为 counter 的 Rust 项目，包含以下文件： 
counter/
├── Cargo.toml
└── src/
    └── main.rs
现在编辑 Cargo.toml，添加 eframe 依赖： 
[package]
name = "counter"
version = "0.1.0"
edition = "2024"  # egui 0.34 使用 Rust 2024 edition

[dependencies]
eframe = "0.34"

说明：eframe = "0.34" 会自动引入 egui（UI 核心）和 wgpu（默认渲染后端）。你不需要单独列出 egui。

保存后，运行以下命令下载依赖： 
cargo build
首次编译可能需要几分钟——egui 及其依赖项不少。后续编译会利用缓存，快得多。

2.2 定义 App 结构体

用你喜欢的编辑器打开 src/main.rs，清空内容，写入以下代码： 
use eframe::egui;

fn main() -> eframe::Result<()> {
    // 创建运行选项，使用默认配置
    let native_options = eframe::NativeOptions::default();

    // 启动应用
    eframe::run_native(
        "我的计数器",                        // 窗口标题
        native_options,                       // 运行选项
        Box::new(|_cc| Ok(Box::new(MyApp::default()))), // 应用创建函数
    )
}

// 应用状态
struct MyApp {
    count: i32, // 计数器当前值
}

impl Default for MyApp {
    fn default() -> Self {
        Self { count: 0 }
    }
}

逐行解释

引入 egui： 
use eframe::egui;
这行引入 egui 模块——所有的 UI 构建 API 都在其中。 main 函数： 
fn main() -> eframe::Result<()> {
注意返回类型是 eframe::Result<()>——这不是标准库的 Result，而是 eframe 定义的别名。 eframe::run_native 是 eframe 的核心启动函数，接受三个参数：
  • "我的计数器" — 窗口标题（字符串）
  • NativeOptions::default() — 运行配置（窗口大小、渲染器、vsync 等，这里全用默认值）
  • Box::new(|_cc| Ok(Box::new(MyApp::default()))) — 一个闭包，告诉 eframe 如何创建你的应用实例
闭包中的 _cc 是 CreationContext，包含窗口创建时的上下文信息（如 Storage）。我们现在用不到它，所以用 _ 前缀忽略。 MyApp 结构体 是你的应用状态的容器——egui 推荐的模式是把所有应用数据放在这个结构体里。目前只有一个 count: i32。 Default trait 是必需的——eframe 需要在启动时创建应用的默认实例。

2.3 实现 eframe::App trait

接下来就是 egui 的核心了。我们需要为 MyApp 实现 eframe::App trait。这个 trait 包含两个重要的方法：
  • logic() — 帧逻辑（数据处理、输入检测、后台任务）
  • ui() — UI 渲染（描述当前帧的界面）
在 impl Default for MyApp 块之后，添加： 
impl eframe::App for MyApp {
    fn logic(&mut self, _ctx: &egui::Context, _frame: &mut eframe::Frame) {
        // 帧逻辑：这里可以放数据处理代码
        // 目前不需要，留空
    }

    fn ui(&mut self, ui: &mut egui::Ui, _frame: &mut eframe::Frame) {
        // UI 渲染：描述当前帧的界面
        // 直接使用 ui 即可——不需要 CentralPanel
        ui.label(format!("点击次数: {}", self.count));

        if ui.button("+1").clicked() {
            self.count += 1;
        }
    }
}

逐行解释

impl eframe::App for MyApp — 为我们的应用结构体实现 App trait。 fn logic(&mut self, _ctx: &egui::Context, _frame: &mut eframe::Frame)：
  • &mut self — 可修改应用状态（如 count）
  • &egui::Context — egui 的中央枢纽（输入、内存、样式）
  • &mut eframe::Frame — 桌面框架提供的帧信息
  • 这个方法叫 logic()——在 egui 0.34 之前，这个方法和 ui() 是合并成一个 update() 的。拆分后代码更清晰。
fn ui(&mut self, ui: &mut egui::Ui, _frame: &mut eframe::Frame)：
  • 这才是"画 UI"的地方
  • 0.34 起，ui 直接由 eframe 传入并覆盖整个窗口——你无需手动创建面板
  • ui.label(...) — 显示一行文本（标签）
  • ui.button("+1") — 显示一个按钮
  • .clicked() — 返回 true 表示本帧按钮刚被点击

⚠️ Immediate Mode 的关键思维：

ui.button("+1") 不是在"创建"按钮——它只是在本帧描述"这里有个按钮"。如果用户点击了它，.clicked() 返回 true。下一帧，同样的代码再次运行，按钮再次被描述——不保留任何持久对象。

2.4 完整代码

将以上代码合并，得到完整的 src/main.rs： 
use eframe::egui;

fn main() -> eframe::Result<()> {
    let native_options = eframe::NativeOptions::default();

    eframe::run_native(
        "我的计数器",
        native_options,
        Box::new(|_cc| Ok(Box::new(MyApp::default()))),
    )
}

struct MyApp {
    count: i32,
}

impl Default for MyApp {
    fn default() -> Self {
        Self { count: 0 }
    }
}

impl eframe::App for MyApp {
    fn logic(&mut self, _ctx: &egui::Context, _frame: &mut eframe::Frame) {
        // 留空：计数器逻辑足够简单，不需要额外的帧逻辑
    }

    fn ui(&mut self, ui: &mut egui::Ui, _frame: &mut eframe::Frame) {
        ui.label(format!("点击次数: {}", self.count));

        if ui.button("+1").clicked() {
            self.count += 1;
        }
    }
}

2.5 运行与效果

在终端中执行： 
cargo run
你将看到一个窗口： 
┌──────────────────────────┐
│  我的计数器            _ □ × │
│                          │
│  点击次数: 0             │
│  ┌─────┐                 │
│  │ +1  │                 │
│  └─────┘                 │
│                          │
└──────────────────────────┘
点击 "+1" 按钮，数字会递增。每次点击，按钮短暂显示蓝色（按下状态），数字加 1。

中文界面版本

如果你想把界面文字改成中文，只需要修改字符串： 
ui.label(format!("点击次数: {}", self.count));
if ui.button("递增").clicked() {
//        ^^^^ 改这里

⚠️ 按钮上的中文可能显示为方框（□□□）或空白——这是因为 egui 默认字体不包含中文字形。我们在第 22 章会详细讲解如何配置中文字体。目前可以先用英文，或者接受暂时的方框——第 22 章会完美解决。

2.6 直觉与回顾

在进入下一章之前，花一点时间感受这段代码中的关键模式：

🤔 问题 1：按钮为什么在 if 判断里？

if ui.button("+1").clicked() {
    self.count += 1;
}
这不是"创建按钮，给它注册回调"。而是"本帧画一个按钮，如果它刚被点击了，就执行 {} 中的代码"。按钮和点击检查是同一个表达式的两部分。

🤔 问题 2：为什么 count 的值没有丢失？

MyApp 结构体由 eframe 持有在内存中。它不会被每帧销毁重建。每次调用 ui() 时，self 指向的是同一个 MyApp 实例。所以 count 的值自然保留。 那么，Widget（如 slider、text edit）的值是怎么跨帧保留的？它们没有存在 MyApp 中——答案是 egui 内部的 Memory 存储。第 18 章会深入讲解。

🤔 问题 3：logic() 和 ui() 有什么区别？

当前计数器过于简单，logic() 是空的。在实际应用中：
  • logic() — 数据处理、快捷键检测、网络请求、定时器
  • ui() — 纯粹的 UI 描述
这种分离是 egui 0.34 的重要改进。第 19 章会详细讲解数据流的最佳实践。

本章小结

  • 在 Cargo.toml 中添加 eframe = "0.34" 即可开始 egui 开发
  • 应用状态存储在 MyApp 结构体中，需要实现 Default 和 eframe::App
  • eframe::App 有两个核心方法：logic()（帧逻辑）和 ui()（UI 渲染）
  • ui.button("...").clicked() 在按钮被点击时返回 true
  • 计数器值保留在 MyApp.count 中——因为 MyApp 由 eframe 持有

use eframe::egui;

fn main() -> eframe::Result<()> {
    let native_options = eframe::NativeOptions::default();

    eframe::run_native(
        "我的计数器",
        native_options,
        Box::new(|_cc| Ok(Box::new(MyApp::default()))),
    )
}

/// 应用状态：存储所有需要在帧之间保留的数据
struct MyApp {
    count: i32,
}

impl Default for MyApp {
    fn default() -> Self {
        Self { count: 0 }
    }
}

impl eframe::App for MyApp {
    /// 帧逻辑：数据处理、快捷键检测、后台任务
    fn logic(&mut self, _ctx: &egui::Context, _frame: &mut eframe::Frame) {
        // 计数器逻辑足够简单，这里不需要额外处理
    }

    /// UI 渲染：每帧描述界面
    fn ui(&mut self, ui: &mut egui::Ui, _frame: &mut eframe::Frame) {
        ui.heading("计数器示例");

        ui.separator();

        // 显示当前计数
        ui.label(format!("点击次数: {}", self.count));

        // 按钮：检测点击并修改状态
        if ui.button("+1").clicked() {
            self.count += 1;
        }

        // 添加一个递减按钮
        if ui.button("-1").clicked() {
            self.count -= 1;
        }

        // 添加一个重置按钮
        if ui.button("重置").clicked() {
            self.count = 0;
        }
    }
}
